# 高校课程标准映射与课程改革审阅平台

面向教研人员、课程负责人和院系审阅人的课程图谱平台，支持培养目标、毕业要求、课程单元、教学活动、考核任务映射，以及有向图检查、覆盖矩阵、拖拽连边、自动保存、批量审核和课程地图导出。

## 技术栈

SvelteKit + Skeleton UI + Svelte stores + SvelteKit Form Actions + TanStack Query + Zod + Vite + TypeScript

## 本地运行

```bash
npm install
npm run dev
```

访问 `http://localhost:62049`，生产构建使用 `npm run build`。

## 核心工作流

- 在培养目标、毕业要求、课程、单元和考核之间建立有向映射。
- 自动检查前置关系、覆盖缺口、重复映射和不完整考核证据。
- 课程负责人提交修订，院系审阅人逐条退回、附议或要求补充证据。
- 比较版本覆盖变化，恢复草稿并导出专业课程地图。
- 在 `/packages` 发起专业认证调阅包：
  - 发起瞬间固定毕业要求、随机抽中的课程、映射与审阅意见（深拷贝快照并标注内容版本）。
  - 按课程逐门分片生成，分片内列出「未审阅 / 已退回」与「缺失证据」清单。
  - 生成失败按**原包号**从第一片未完成课程续作，已完成分片幂等不重复。
  - 两名管理员并发补材料时，只接收基于当前内容版本的首次提交；晚到或版本落后的提交保留为草稿，可按当前版本重新提交。
  - 图谱或审阅结论一变（内容版本号推进），未交付调阅包立即失效，可另起新包号重算（新旧包双向关联）；已交付包冻结原快照，只提供与当前图谱的差异追溯；纯节点拖拽布局不推进版本。
  - 旧本地数据缺少版本号时自动兼容升级（图谱补 `contentVersion=1`，调阅包注册表补空集合）。
